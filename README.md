<h1 align="center">Encriptador / Desencriptador en Python</h1>

Esta hecho con las siguientes librerias: Cryptography Fernet, hashlib y con base64.

Es un programa ejecutable en Windows, el cual le pide al usuario una clave aleatoria para encriptacion y posterior desencriptacion.

La encriptacion realizada por el programa es de <h1>ALTA</h1>alta complejidad ya que tiene hasta un maximo de 18.000 millones de posibilidades.
